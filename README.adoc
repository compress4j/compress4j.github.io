= Hominux Site

Home page and https://antora.org/[Antora] documentation for the Hominux projects, published at https://hominux.com and https://hominux.com/docs.

== Layout

* `home/` holds the static home page, served at the site root.
* `antora-playbook.yml` builds the documentation into `build/site/docs`.

== Usage

. `make` installs, builds and serves the site from `build/site`.
